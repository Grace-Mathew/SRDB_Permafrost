# PNNL 2026 Internship Project
This project was created to help determine the correlation between Permafrost and lowered soil respiration using MAT, MAP, and gleisoil's. 
Raw data was from the Soil Respiration Database, WorldClim Database, and the Circumploar Raster Database.
This project can be used for future research into global warming and understanding its impact on different regions through soil respiration.
